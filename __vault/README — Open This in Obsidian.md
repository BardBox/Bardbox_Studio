# 👋 How to Use This Vault

## Setup (One Time)

1. Open **Obsidian**
2. Click **"Open folder as vault"**
3. Select: `D:\Aadil tai\bizcivitas\Bardbox_Studio\__vault`
4. Done — all notes will appear

---

## Daily Workflow

1. Open `Daily/` folder
2. Duplicate `Templates/_Template Daily`
3. Rename to today's date: `YYYY-MM-DD`
4. Fill in First Half tasks in morning
5. Fill in Second Half tasks after lunch
6. End of day → complete the wrap-up section

---

## Recommended Obsidian Plugins

Install these from Settings → Community Plugins:

| Plugin | Why |
|---|---|
| **Calendar** | Visual calendar — click a date to open/create that day's note |
| **Periodic Notes** | Auto-create daily notes from template |
| **Dataview** | Query your notes like a database (e.g., all open bugs) |
| **Templater** | Auto-fill date in templates |
| **Folder Note** | Click a folder to see its overview |

## Obsidian Tips

- `Ctrl+O` → Quick open any note
- `Ctrl+P` → Command palette
- `[[` → Link to another note
- `- [ ]` → Checkbox task
- `Ctrl+Enter` → Toggle checkbox done
